# 活树

吃掉信息流，长出一本个人正典。

这是一个**自包含的 Chrome 扩展**（0.4.16），不需要 Python，也不需要本机服务器。推文、知识树、生长日志、旁注和对话都存在浏览器里。

## 在本地加载（Chrome / Edge / 其他 Chromium）

```bash
git clone https://github.com/walterKomarek/huoshu.git
cd huoshu
```

1. 打开 Chrome（或 Edge），地址栏输入 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选中刚刚克隆下来的 `huoshu` 仓库根目录（里面有 `manifest.json`）
4. 若已经加载过：在扩展卡片上点「重新加载」，然后关掉旧的活树标签页再打开

**重要**：只刷新活树网页本身不会更新功能。必须先在扩展管理页点「重新加载」，再用弹窗里的「刷新已打开的活树页」，或关掉旧标签重新打开。

版本变更见仓库内 `CHANGELOG.md`。本扩展不需要 Python，也不需要本机服务器；数据默认存在浏览器本地。对话功能如需接大模型，把 API Key 填进扩展弹层即可，密钥只存在本机，不会进仓库。

## 使用

打开 [x.com](https://x.com)，每条推文旁点「存入活树」。成功后按钮会变成「已生长 ✓」。知识流里**只有你存进去的叶子**，不会再自动长出示例推文。

点浏览器工具栏的活树图标 → 「打开活树」，即可看树、前沿、知识流、拐点、生长日志、旁注、对话。左上角版本号应为当前版本（0.4.16）。

升到 0.4.16 后，左侧可选择「植入跟进骨架」（只补缺失的枝，不改你已有的目录）。拐点清单由你确认状态；论文或事件不会自动标成「已跨过」。可用「导出判断快照」对照终局、拐点与旁注。

### 前沿（每日自动 + 手动）

- **每天约 9:00（上海时区）** 自动刷新前沿清单
- 前沿页右上角有 **「更新前沿」** 按钮，随时手动拉取
- 刷新顺序：若配置了远程 URL → 用远程；否则 **arXiv**（具身 / VLA / 世界模型 / 人形 / **数据层**）+ **Hugging Face Daily Papers** + **行业事件**；再不行则用扩展内置清单
- 可在 `chrome.storage` 写入 `frontierUrl` 指向你自己的 JSON（格式同 `app/frontier.json`）

### 自己长枝（完全手动）

左侧知识树可以随意改：

- 点「+ 新枝」加一根**顶层**主干
- 悬停某枝，用「+ / 改 / 删」加子枝、改名或剪掉
- 剪掉时，这枝上的叶子会移到上一级（没有上一级则进「未分类」）

默认会带一根顶层「具身智能」。其他枝按你的兴趣自己加即可。存入时会尽量按标题/标签自动挂到最接近的枝；挂错了可以在知识流或详情里用「挂到」下拉框随时改挂。

### 真正问答

对话要接模型。点浏览器工具栏的**活树图标**，在弹层里选 DeepSeek / OpenAI / Groq / SiliconFlow（或自定义），把 API Key 贴进密码框，点保存。状态行出现「对话已接 DeepSeek」之后，活树才会按你的知识库作答，而不是拼检索摘录。

密钥只存在 `chrome.storage.local`，只发给你选的那家接口。
